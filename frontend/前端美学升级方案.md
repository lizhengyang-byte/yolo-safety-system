# 工地 AI 安全监测系统 — 前端美学升级方案（v1 · 待批准）

> 范围：**只优化视觉/交互观感（配色、排版、层次、动效、组件皮肤）**，不涉及任何业务逻辑、接口、数据处理、路由行为、字段含义。
> 约束：所有 `<script setup>` 内的逻辑保持原样；仅在模板中增加纯展示的 class / 包裹元素，样式集中在全局设计系统 + 各页 scoped 样式。

---

## 1. 现状评估（为什么需要升级）

| 维度 | 现状 | 问题 |
|---|---|---|
| 设计系统 | 无统一 token，颜色/圆角/间距散落在各页 style | 观感不统一，维护成本高 |
| 侧栏/顶栏 | 纯色 `#001529` 侧栏 + 白顶栏 | 平淡、无品牌感、无层次 |
| 卡片/表格 | Element Plus 默认皮肤，直角感、阴影弱 | 页面"贴平"，缺少呼吸感和聚焦 |
| 图表 | ECharts 默认配色、默认网格 | 与整体品牌色脱节 |
| 登录页 | 单一线性渐变 + 白卡片 | 缺少"AI 产品"第一印象 |
| 细节 | emoji（⚠️📖✅❌）混排、pagination/空状态默认样式、无页面过渡 | 精致度不足 |
| 工程瑕疵 | `index.html` 标题为乱码（GBK 被当 UTF-8） | 浏览器标签页标题显示错误 |

---

## 2. 设计方向（推荐 A，可选 B/C）

**A. 「AI 安全指挥中心」深空科技蓝 + 明亮内容区（推荐）**
- 深色玻璃感侧栏 + 明亮内容区，兼顾专业感与可读性；
- 主色电光蓝 `#2F6BFF → #4F9CFF`，点缀青 `#22D3EE`；语义色：成功 `#22C55E`、警告 `#F59E0B`、危险 `#EF4444`；
- 内容区浅灰蓝 `#F5F7FB` + 极淡点阵/径向高光；卡片 14px 圆角、柔和分层阴影、1px 细描边、悬停上浮；
- 数字用等宽数字（tabular-nums），层次分明；
- 动效 180–240ms `cubic-bezier`，页面淡入位移、卡片悬停、按钮按压反馈。

**B. 极简浅色专业风**：全浅色、低饱和，克制留白（偏传统后台）。
**C. 深色全屏大屏风**：整体深色，适合投屏指挥中心，但日常表单阅读略累。

> 默认按 A 执行；如你更喜欢 B/C 可在批准时指明。

## 3. 分模块优化清单

### 3.1 设计系统底座（新增）
- 新增 `src/styles/variables.css`：颜色、间距、圆角、阴影、字体、过渡等 CSS 变量。
- 新增 `src/styles/element-overrides.css`：通过 Element Plus CSS 变量（`--el-color-primary` 等）统一按钮、输入、表格、标签、分页、弹窗、抽屉皮肤。
- 新增 `src/styles/index.css`：全局背景、滚动条、排版基线、页面过渡类。
- `main.ts` 引入全局样式；`App.vue` 更新基础字体/背景/滚动条。

### 3.2 布局壳（MainLayout）
- 侧栏：深空渐变 + 径向光晕、品牌 Logo 图标字标、菜单分组小标题、激活项渐变胶囊 + 左侧发光条、悬停动效。
- 顶栏：毛玻璃吸顶、页面标题 + 面包屑感、圆形头像、精致铃铛徽标、细分割线。
- 内容区：统一内边距、最大宽度容器、`router-view` 淡入位移过渡。
- （可选，纯 UI）侧栏折叠按钮，仅改变展示宽度。

### 3.3 登录页
- 全屏「极光/网格」动态渐变背景 + 玻璃拟态卡片、品牌区、输入聚焦光晕、渐变主按钮、加载态美化。
- 字段与登录逻辑完全不变。

### 3.4 数据看板（Dashboard）
- KPI 指标卡改为带图标/渐变的彩色磁贴，悬停上浮，数字等宽。
- 卡片头统一「主题色竖条 + 图标」样式。
- 四张 ECharts 统一品牌色板：趋势渐变面积、圆角柱、环形饼图、统一 tooltip 皮肤；容器自适应。
- "系统说明"改为信息面板样式。

### 3.5 实时监控 / 临时演示
- 视频舞台：圆角框 + 柔光边、扫描线/角标装饰、状态胶囊（呼吸点）、玻璃控制条。
- 演示参数栏、统计磁贴、抓拍时间线统一皮肤与动效。
- 加载遮罩 spinner 精修；`MonitorCell` 角标/名称/焦点态重绘。

### 3.6 列表与表单页（摄像头 / 违规 / 预警 / 日志）
- 卡片、筛选区（浅色面板）、表格（表头底色、斑马纹、悬停高亮、圆角标签胶囊）、按钮、分页、空状态统一皮肤。
- 弹窗/抽屉：圆角、头部主题条、背景模糊。
- 缩略图悬停放大、证据图查看器样式优化。

### 3.7 细节与工程打磨
- 页面切换过渡、卡片/按钮/行悬停微交互、`focus-visible` 可见焦点。
- 用 Element Plus 图标替换 chrome 区域的 emoji（业务文案里的保留或适度替换）。
- 修复 `index.html` 标题乱码、`lang`、加内联 SVG favicon。
- 响应式断点：KPI 卡、双栏图表、监控网格在小屏自适应。
