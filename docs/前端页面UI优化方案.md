# 前端页面 UI 全面优化方案

> 适用范围：`frontend/`（Vue3 + Element Plus + ECharts + flv.js）
> 约束：**只改前端视觉与交互表现，不改任何业务逻辑**（接口调用、数据流、判定规则、路由守卫、字段含义一律保持原样）
> 版本：v1.0（待批准）

---

## 一、现状诊断

| 模块 | 当前问题 |
| --- | --- |
| 全局 | 直接使用 Element Plus 默认主题，没有设计变量层；卡片无圆角层次、背景单一（#f0f2f5）；字号/间距/颜色散落在各页面，缺少统一规范 |
| 主框架 | 侧边栏为纯色 #001529，logo 区只有一行文字；菜单无选中指示条与图标层次；顶栏标题小、无面包屑、无用户头像；铃铛是默认按钮 |
| 登录页 | 常规渐变 + 小白卡，缺少品牌标志与安全行业视觉；表单元素拥挤，无辅助说明 |
| 数据看板 | 指标卡只有大号数字，无图标/趋势/单位；ECharts 使用默认配色与默认网格，视觉偏“毛坯”；卡片标题栏朴素；栅格节奏单一 |
| 列表页（摄像头/违规/日志/预警） | 表格默认边框+斑马纹，工具栏与筛选区层级不清；分页贴底无容器；详情抽屉与描述列表缺少质感；状态标签配色不统一 |
| 预警中心 | 规则表与事件表两张卡直接堆叠；未读事件没有足够醒目的视觉强调；严重度/冷却等关键信息不突出 |
| 监控 / 演示 | 视频舞台没有“监控大屏”质感；控制条是浅灰平铺；统计卡是纯数字；加载遮罩、AI 标签样式较原始 |
| 动效 | 仅有零散的 pulse / spin；无页面切换过渡、无卡片 hover、无按钮反馈细节 |
| 响应式 | 指标卡固定 4 列、图表固定 14/10 栅格，窄屏会挤压；缺少断点适配 |

## 二、设计目标与风格方向

**关键词：专业、可信、科技感、中后台效率**

- **推荐方向：浅色专业版 + 深蓝侧边栏（Modern SaaS / 智慧工地指挥台）**
  - 内容区浅灰蓝底（#F4F7FB），白色卡片 + 柔和投影，信息密度适中。
  - 侧边栏深蓝渐变（#0B1B33 → #102A4C），保留“指挥中心”的稳重感。
  - 主色科技蓝，安全橙作为强调色，危险红只用于违规/预警，形成清晰的语义色体系。
- 备选方向：全深色大屏版（适合展厅/大屏投放，但改造量大、白天办公阅读性下降）。
- 备选方向：保持现有配色，仅做精细化（改动最小，但提升有限）。

### 设计令牌（Design Tokens）

| 类别 | 取值 |
| --- | --- |
| 主色 | `#2F6BFF`（hover `#4C82FF` / active `#1F55D6` / 浅底 `#EAF1FF`） |
| 安全橙 | `#FF7A45`（渐变 `#FF9A62 → #FF6A2B`） |
| 危险红 | `#F04438`；成功绿 `#12B76A`；信息蓝 `#0BA5EC` |
| 文本 | 主 `#101828` / 次 `#475467` / 弱 `#98A2B3` / 反白 `#FFFFFF` |
| 背景 | 页面 `#F4F7FB`、卡片 `#FFFFFF`、表头 `#F8FAFD`、侧栏渐变 `#0B1B33 → #102A4C` |
| 边框 | `#E4E9F2`（hover `#CBD5E1`） |
| 圆角 | 6 / 10 / 14 / 20 px（按钮 10、卡片 14、弹窗 16） |
| 阴影 | sm `0 1px 2px rgba(16,24,40,.06)`；md `0 6px 24px rgba(16,24,40,.08)`；lg `0 18px 48px rgba(16,24,40,.12)` |
| 字体 | `Inter`, `PingFang SC`, `Microsoft YaHei`；12/13/14/16/20/28/40；数字用等宽数字（tabular-nums） |
| 间距 | 4 / 8 / 12 / 16 / 20 / 24 / 32 |
| 动效 | 150ms / 250ms，缓动 `cubic-bezier(.4,0,.2,1)` |

## 三、分页面改造清单

### 1. 全局（新增 `src/styles/`）
- `tokens.css`：上述设计令牌，全部以 CSS 变量输出。
- `element-overrides.css`：统一覆盖 Element Plus 的 CSS 变量与组件表现（主色、圆角、按钮高度、卡片阴影、表格表头/行 hover、弹窗/抽屉圆角、输入框、标签、分页、下拉、消息提示）。
- `base.css`：全局重置、滚动条、选中色、页面背景、标题层级、通用工具类（`.page`、`.page-head`、`.panel`、`.stat-*`）。
- `animations.css`：页面淡入上移、卡片 hover 抬升、铃铛脉冲、数字/骨架过渡。
- 在 `main.ts` 中于 `element-plus/dist/index.css` 之后引入。

### 2. 主框架 `layout/MainLayout.vue`
- 侧边栏：深蓝渐变 + 顶部品牌区（图标徽标 + 系统名 + 英文副标题）；菜单项加圆角选中胶囊、左侧亮条、hover 微亮、图标统一。
- 顶栏：毛玻璃背景 + 底部细边；左侧显示当前页标题与简短面包屑（数据看板 / 当前页）；右侧铃铛带未读脉冲动效、用户区改头像胶囊 + 下拉。
- 主内容区增加统一内边距与最大宽度，路由切换加淡入过渡。
- （可选）侧边栏折叠按钮，仅前端状态，不影响路由。

### 3. 登录页 `views/Login.vue`
- 左右分栏：左侧品牌区（深蓝渐变 + 网格/光晕 + 安全帽线条图形 + 标语），右侧白色登录面板。
- 卡片玻璃质感、圆角 20，标题层级与副标题；输入框加图标与更大点击区域；登录按钮渐变 + hover 光效；底部版权/版本信息。
- 窄屏自动折叠为单列。

### 4. 数据看板 `views/Dashboard.vue`
- 顶部工具栏改为页面头部：标题 + 说明 + 时间范围分段控件 + 导出按钮。
- 4 张指标卡重构：图标色块 + 数字 + 标签 + 趋势/单位说明；不同指标不同强调色；hover 抬升。
- 4 张图表卡统一“卡片头（标题 + 副标题/图例）+ 内容”结构；ECharts 主题统一：品牌色系、浅网格线、圆角柱、渐变面积、环形图中心显示总数、tooltip 统一圆角阴影。
- 栅格响应式：`el-col` 使用 `:xs/:sm/:md/:lg` 断点；图表高度自适应。
- “系统说明”卡片改为信息块样式。

### 5. 摄像头管理 `views/camera/index.vue`
- 页面头部（标题 + 状态说明 + 新增按钮）。
- 表格视觉升级：表头浅底、行 hover、状态标签统一色、操作按钮分组。
- 新增/编辑弹窗统一圆角与间距；RTSP 测试结果改胶囊状态条。

### 6. 违规记录 `views/violation/index.vue`
- 筛选区收进“筛选栏”卡片，控件对齐、间距统一，查询/重置按钮区分主次。
- 表格缩略图加圆角与 hover 放大；详情抽屉重构：图片区深色背景 + 信息卡 + 检测明细表样式统一。
- 空状态、分页样式统一。

### 7. 安全日志 `views/log/index.vue`
- 与违规记录共用页面头部/筛选栏/表格/抽屉视觉规范；Excel 导出按钮突出。
- 顶部说明 Alert 改为轻量信息条。

### 8. 预警中心 `views/warning/index.vue`
- 规则区与事件区改为“卡片 + 区块标题”结构；未读事件整行淡红底 + 左侧色条 + 未读圆点。
- 规则启用状态、触发条件用更强的信息层级；统计小徽标（启用规则数/未读事件数）。
- 弹窗与条件输入行视觉统一。

### 9. 实时监控 `views/monitor/`
- 页面头部：标题 + 说明 + 摄像头多选/轮播/全屏控件整理为工具条。
- `MonitorCell`：视频区加圆角、外发光、状态角标（在线绿点呼吸）、AI 标签渐变、底部名称渐隐条；聚焦态描边高亮。
- 网格间距与空状态优化；全屏时铺满。

### 10. 临时演示 `views/demo/index.vue`
- 舞台区加“监控窗口”外框（深色 chrome、圆角、阴影），顶部操作区与参数条分层。
- 统计卡统一指标卡样式；时间线缩略图加圆角 hover 缩放与时间标签。
- 加载遮罩、违规横幅、帧率标签统一视觉语言。

## 四、交互与动效
- 路由切换：淡入 + 轻微上移（150–250ms）。
- 卡片 hover：阴影加深 + 上移 2px。
- 按钮：按下缩放、主按钮渐变/光效。
- 铃铛：有未读时轻微脉冲 + 数字徽标。
- 表格行：hover 高亮；缩略图 hover 放大。
- 统一 loading 骨架/遮罩风格。

## 五、响应式
- 断点：≥1440 / 1024–1440 / 768–1024 / <768。
- 指标卡 4→2→1 列；图表卡 2 列→1 列；表格在窄屏允许横向滚动；侧边栏窄屏可折叠。

## 七、验收标准
1. `npm run build` 通过，无类型/构建错误。
2. 浏览器控制台无新增报错。
3. 登录、看板、监控、演示、摄像头、违规、预警、日志 8 个页面在 1440/1024/768 宽度下布局正常。
4. 所有功能（筛选、分页、导出、增删改、开关、视频检测）行为与改造前一致。
5. 视觉统一：颜色、圆角、阴影、间距、字号全部来自设计令牌，无“野生”硬编码色值（图表配置除外）。

## 八、风险与回滚
- 风险：全局 Element Plus 覆盖可能影响个别组件；通过限定选择器与逐页验证控制。
- 风险：模板结构调整误伤绑定；只添加装饰性 class/包裹元素，不动绑定。
- 回滚：改动集中在上述文件，可用 `git checkout -- frontend/` 一键还原（建议改造前确认工作区干净）。
