## 这个系列讲什么？

先讲一个真实场景：工地几十个摄像头天天在录，但安全员不可能同时盯住所有画面。有人没戴安全帽、没穿马甲、没戴口罩——往往是出了事故才被发现。

这套系统干的事就是：**让 AI 替人盯着摄像头**——检测到违规瞬间自动抓拍、自动留痕、自动统计、自动预警，安全员打开网页后台就能看到全部证据和报表。

仓库里是一套**完整可运行**的实现：FastAPI 后端 + YOLOv8 推理 + Vue3 前端 + 流媒体转发 + Docker 部署。这个系列博客就是把这套系统**拆开揉碎**讲给你听。

## 动手第一步：把项目跑起来

```bash
# 后端（SQLite，自动建表，端口 8000）
cd backend
uv sync
uv run uvicorn app.main:app --reload

# 前端（端口 3000，已代理 /api 与 /images 到 localhost:8000）
cd frontend
npm install
npm run dev
```

打开 http://localhost:3000（账号 `admin / admin123`），点左侧「临时演示」——用笔记本摄像头就能体验完整流程：检测 → 判定 → 违规抓拍 → 入库 → 预警，**不需要任何监控设备**。
