## 开头：光看不练是学不会的

读 10 篇博客 ≠ 会做系统。真正学会的标志是：**你能动手改代码、能独立做一个功能、能在答辩时把原理讲清楚**。这一篇就是你的"实践路线图"。

## 2. 实验 1：系统跑起来 + 演示链路体验

```bash
cd backend && uv sync && uv run uvicorn app.main:app --reload
cd frontend && npm install && npm run dev
```

1. 打开 http://localhost:3000，登录（admin / admin123）；
2. 左侧菜单逐个点开：数据看板 → 临时演示 → 违规记录 → 安全日志 → 预警中心；
3. 进「临时演示」：授权摄像头 → 开始演示 → **对着镜头摘口罩/取下帽子**，观察画框与横幅；
4. 回「违规记录」，找到记录 → 点开详情 → **切换原图/标注图**；
5. 在「预警中心」新建规则（60 分钟 ≥ 2 次 no_mask）→ 再演示两次违规 → 观察事件生成与铃铛。

**验收**：能说出演示链路完整数据流；能指出入库记录 `camera_id=0`、`camera_name="临时演示"` 的含义。

**加分项**：打开 http://localhost:8000/docs，用 Swagger 直接测 `/api/demo/detect`——体验"接口文档就是测试工具"。

## 3. 实验 2：看数据、改配置、观察变化

1. 把 `backend/app/config.py` 的 `DEMO_CONF_THRESHOLD: 0.5 → 0.9`，重启后端，演示页识别变严；
2. 把 `VIOLATION_RULE` 里 `"no_mask": "NO-Mask"` 注释掉，演示时看"口罩违规"还能触发吗（不能！）——理解"判定规则 = 模型输出与违规类型的映射"；
3. 改回；打开 `inference/config.local.yaml`，对比与 `config.py` 的字段，画一张"两处配置对应关系表"。

**验收**：能解释"为什么灵敏度滑块调高 = 更严格"；能说出 `VIOLATION_RULE` 三行含义。

## 4. 实验 3：手工上报一条违规（API 实测）

```bash
curl -X POST http://localhost:8000/api/violations/with-image \
  -F "file=@violation.jpg" \
  -F "anno=@violation_anno.jpg" \
  -F "camera_id=0" -F "camera_name=手工测试" \
  -F "violation_type=no_helmet" -F "confidence=0.85" \
  -F 'detections=[{"cls_name":"NO-Hardhat","conf":0.85,"box":[10,10,200,300]}]'
```

1. 在「违规记录」页确认新记录（含标注图与检测明细）；
2. 新建预警规则（阈值 1）→ 再上报一次 → 确认 `warning_events` 生成、铃铛未读 +1；
3. 查看 SQLite 数据库：`backend/yolo_safety.db`，用 DB Browser 看 `violations` 表结构。

**验收**：能解释 `with-image` 每个字段；能说出预警触发三层逻辑。

## 5. 实验 4：修改证据图与前端配色（双份同步实战）

1. 修改 `backend/app/detection/annotate.py` 与 `inference/annotate.py`（**两处！**）的 `VIOLATION_LABELS`，加上 `⚠` 后缀；
2. 同步改 `frontend/src/constants/violations.ts` 的 `VIOLATION_TYPE_MAP`；
3. 重启后端演示一次违规，检查标注图横幅、演示页横幅、违规记录中文一致；
4. **故意只改一处**，观察"正式链路与演示链路标注不一致"的后果。

**验收**：能说出换模型 5 处清单；理解"双份同步"为什么是核心纪律。

## 6. 实验 5：新增看板指标（后端 + 前端全链路）

新增指标"平均置信度"：

1. **后端**：`logs.py` 的 `/dashboard` 加字段：
   ```python
   avg_conf = (db.query(func.avg(Violation.confidence))
       .filter(Violation.created_at >= start_dt).scalar() or 0)
   # 返回加 "avg_conf": round(avg_conf, 3)
   ```
2. **前端类型**：`api/violation.ts` 的 `DashboardData` 加 `avg_conf: number`；
3. **前端 UI**：`Dashboard.vue` 统计卡区域加"平均置信度"卡片；
4. 验证：`vue-tsc --noEmit` + `vite build` 通过。

**验收**：完整走通"后端接口 → 前端类型 → 前端渲染"三件套。

## 7. 实验 6：用 AI 完成一个小需求（五步循环）

题目三选一：
- **A**：违规记录页增加"按点位筛选"（后端联表 cameras 取 location，前端加筛选下拉）；
- **B**：预警事件点击跳转到对应违规记录列表（前端路由 + 筛选参数传递）；
- **C**：新增 `GET /api/logs/weekly-compare`：本周 vs 上周每日违规数对比。

流程（用第 10 篇模板）：
1. 用模板 1 下需求（带项目约束：双份同步、本地时间戳、vue-tsc 验证）；
2. 审方案：检查文件落点、接口设计、与现有代码一致性；
3. 让 AI 实现；
4. 验收：后端实跑实测（贴响应）、前端 vue-tsc + vite build；
5. 复盘：更新 CLAUDE.md、写清 commit message。

## 8. 课程设计选题（5 个方向）

### 方向 A：模型级扩展——换模型适配（★ 推荐，最有"AI 味"）
- 选题：把 ppe.pt 换成你训练的模型（YOLOv8 训练的安全帽检测/车辆检测），完整走"换模型 5 处清单"；
- 加分：自己用 roboflow/自制数据集微调模型（如"未系帽带"），训练脚本 + 评估报告（mAP）；
- 覆盖：第 7 篇 + 机器学习基础。

### 方向 B：功能级扩展——新业务模块
- 选题：加"车辆未冲洗识别"或"危险区域入侵检测"（画面划禁区，person 框与禁区 IoU 判定）；
- 加分：复用预警中心（新违规类型 + 新规则 + 新报表）；
- 覆盖：第 6/9 篇 + 第 8 篇。

### 方向 C：数据级扩展——报表与分析能力
- 选题：周报/月报升级为"自定义时间范围 + 多项目对比报表"；看板加"月度环比"；
- 加分：用 pandas 做统计分析 + 生成可视化报告；
- 覆盖：第 9 篇 + 数据分析。

### 方向 D：工程级扩展——部署与稳定性
- 选题：Kubernetes 化部署 / 推理服务热更新摄像头列表（轮询后端而非启动时拉取）/ 违规图片自动归档清理；
- 加分：性能测试报告（并发上报、多路摄像头）；
- 覆盖：第 5 篇 + 运维。

### 方向 E：AI 辅助开发研究（★ 前沿，答辩亮点）
- 选题：用本仓库做"AI 辅助开发效率实验"——同一需求，人工实现 vs AI 辅助实现，对比时间/质量/代码量；
- 加分：设计你自己的提示词模板库与验证清单；
- 覆盖：第 10 篇 + 软件工程。

## 9. 扩展方向（8 个"下一步"）

1. **公共包抽取**：把 detector/judge/annotate 抽成独立包，彻底解决双份同步；
2. **数据库迁移工具**：引入 Alembic 管理 schema 演进，替代手写 ALTER；
3. **多用户与权限**：角色（管理员/安全员/访客）+ 操作审计日志；
4. **移动端**：小程序/APP 推送预警（用 WebSocket 替代 10s 轮询）；
5. **模型热更新**：运行时切模型权重，不必重启；
6. **视频片段留痕**：违规前 3 秒短视频，比单张图证据力更强；
7. **准确率回测**：定期用标注集回测模型，生成 mAP 趋势报告；
8. **多项目（多工地）架构**：一个平台管多个工地（当前 location 字段是雏形，可扩展为 project_id 体系）。

## 10. 答辩高频问题与答题思路

| 问题 | 答题要点 |
|---|---|
| 为什么选 YOLOv8？ | 实时性（一阶段）+ 定位能力 + Ultralytics 生态；对比两阶段检测/图像分类 |
| 什么是 direct 判定模式？ | ppe.pt 直接输出 NO-* 违规类，出现即违规；对比 person_iou（正类装备 + IoU） |
| 推理服务怎么多路并发？ | 每摄像头一个 StreamWorker 线程；每 N 帧检测降负载；断流重连 + 心跳 |
| 演示链路和正式链路逻辑一致吗？ | detector/judge/annotate 双份同步（逐行一致），演示复用后端独立加载的模型 |
| 数据库时间戳有什么坑？ | SQLite CURRENT_TIMESTAMP 是 UTC 差 8 小时 → 统一 Python 本地时间 + 存量迁移；MySQL 无此问题 |
| 预警中心怎么防刷屏？ | 去重（dedup_seconds）+ 事件 10 分钟冷却 + 事件记录窗口内累计次数 |
| PDF 中文怎么解决？ | reportlab 内置 STSong-Light CID 字体（无需系统字体）；对比 annotate 的 PIL 方案 |
| reportlab 趋势图为什么手绘？ | 4.2 重构后 LineChart data API 失效 → shapes 原语手绘 + 标签自适应间隔 |
| 前端怎么做到"AI 感"？ | canvas 叠加检测框（前后端配色一致）+ 演示统计/FPS + 标注证据图 |
| 换模型要改哪些地方？ | 5 处：inference 配置、backend config、双份 annotate、前端 constants、原始脚本 |
| 你怎么用 AI 开发的？ | 五步循环 + 提示词模板 + CLAUDE.md 沉淀 + 验证证据（实跑实测/vue-tsc/build） |
| 系统还能怎么改进？ | 从第 9 节扩展方向里选 2~3 个，说明价值与工作量 |
